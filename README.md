# Invoice . Co

> **A smart, elegant, and responsive invoice generator built with React**

Create professional invoices in seconds, preview them instantly, and download them as a polished PDF — all with a clean and intuitive interface.

---

## 🌟 What makes it special?

**Invoice . Co** is designed to make invoicing simple, fast, and visually appealing.
With a smooth user experience and automatic calculations, it helps you generate invoices without any manual hassle.

---

## ✨ Key Features

* Beautiful gradient-based UI
* Fully responsive design for mobile, tablet, and desktop
* Add company and client details with ease
* Dynamically add or remove invoice items
* Automatic calculation of:

  * Subtotal
  * Tax
  * Grand total
* Live invoice summary view
* Download invoice as a professional PDF
* Seamless page navigation with React Router
* Shared invoice data using Context API

---

## 🧰 Tech Stack

This project is powered by a carefully chosen set of modern tools and libraries:

| Technology | Purpose |
|------------|---------|
| ⚛️ **React** | Frontend UI framework |
| 📝 **Formik** | Form handling & validation |
| 🌐 **React Router DOM** | Page navigation |
| 🔄 **Context API** | Global state management |
| 🎨 **Tailwind CSS** | Utility-first styling |
| 📄 **jsPDF** | PDF generation |
| 📊 **jspdf-autotable** | Structured table export in PDF |

## 🚀 Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/your-username/invoice-co.git
cd invoice-co
```

### 2) Install dependencies

```bash
npm install
```

### 3) Start the development server

```bash
npm start
```



---

## 📦 Install Required Packages

```bash
npm install formik react-router-dom jspdf jspdf-autotable
```

If Tailwind CSS is not already configured, install and set it up as well.

## 🧾 How It Works

### 1. Generate an Invoice

Go to the **Generate invoice** page and enter:

* Company name
* Client name
* Address
* Invoice number
* Date
* Item description
* Quantity
* Rate

Click **Generate Invoice** to save the invoice details.

### 2. Preview the Invoice

Open the **Invoice & download** page to view:

* Client details
* Item table
* Subtotals
* Tax
* Final amount

### 3. Download as PDF

Click **Download PDF** to export a clean invoice file instantly.
